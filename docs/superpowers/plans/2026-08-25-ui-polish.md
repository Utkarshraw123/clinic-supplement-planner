# Supplement Selection Database — Plan 4: UI Polish Implementation Plan

> Visual-verification-gated (not TDD): there are no unit tests for "looks good". The 41 existing logic tests MUST stay green — this plan changes presentation only, never `lib/*` behaviour. Each task ends with a browser screenshot as its gate.

**Goal:** Replace the plain inline-styled scaffolding with a single cohesive design system — a clinical, calm, professional look — applied across every screen, plus a proper app shell with navigation the app currently lacks.

**Approach:** Highest-leverage first. Because every page uses semantic HTML (`form`, `input`, `button`, `select`, `h1`, `ul`) with only light inline layout styles, a strong global stylesheet transforms the whole app at once. Then add an app shell (top nav) for cohesion, a small class kit (`.card`, `.badge`, `.btn`), and targeted rewrites of the hero screens (login, plan builder, catalog, patient profile).

**Design system (from UI UX Pro Max data — Medical Clinic / B2B Service):**
- Font: **Plus Jakarta Sans** (Google Fonts via `next/font`), weights 400/500/600/700.
- Palette (green-forward, cohesive with the PDF's `#0F6E56`):
  - `--brand` #0F6E56 · `--brand-hover` #0C5A46 · `--brand-tint` #E1F5EE · `--brand-tint-2` #F0FAF6
  - `--canvas` #F7F8F6 · `--surface` #FFFFFF
  - `--ink` #1C2B26 · `--ink-2` #566963 · `--ink-muted` #8A968F
  - `--border` #E4E8E4 · `--border-strong` #D2D8D3
  - Danger (block) `--danger` #B42318 / `--danger-bg` #FEF3F2
  - Warning `--warn` #B54708 / `--warn-bg` #FFFAEB
  - Success `--ok` #067647 / `--ok-bg` #ECFDF3
- Radius: 12px cards, 8px controls. Shadows: subtle only.

**Tech Stack:** Next.js 14, `next/font/google` (no new deps beyond that). Tailwind stays available but we drive it with CSS variables + hand-written component CSS for full control.

import "./globals.css";
import { Plus_Jakarta_Sans } from "next/font/google";

const jakarta = Plus_Jakarta_Sans({ subsets: ["latin"], weight: ["400","500","600","700"], variable: "--font-sans" });

export default function RootLayout({ children }: { children: React.ReactNode }) {

    <html lang="en" className={jakarta.variable}>
